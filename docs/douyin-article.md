标题：三个软件来回切，我嫌烦，自己写了个开源的 CoreFTP

老实说，我忍这个事挺久了。

平时给服务器传文件，我得开个 FTP 客户端。传完了想改配置、看日志，又得再开个 SSH 终端。有时候传的是压缩包，上去之后还得敲命令解压。

三个软件，来回切。

烦不烦？反正我烦了。

后来我就想，能不能自己写一个，把这些事放一块？

于是就写了 CoreFTP。

它大概长这样——

CoreFTP 主界面

主界面是双栏的，左边我电脑，右边服务器。传文件直接拖，从左边拖右边就是上传，反过来就是下载。

覆盖前会弹个窗问一下——因为我有一次手滑，旧配置把新配置盖了，折腾半天才找回来。所以这个保护我是故意加的。

界面方面我顺手做了自定义标题栏、几套配色，还有夜间模式。我经常熬夜改代码、传文件，深色模式确实舒服一点。

CoreFTP 夜间模式

核心功能就三个。

第一个是传文件。

SFTP 连服务器，双栏浏览，拖拽上传下载，断点续传，批量操作，该有的都有。

站点多了我就按分类放侧栏，开发、测试、生产分开。密码不走明文配置文件，我接进了 Windows 凭据管理器，截图或者分享屏幕的时候不怕密码露出来。

CoreFTP 站点管理

第二个是 SSH 终端。

连上 SFTP 之后，点一下就能开终端。改 Nginx 配置、看错误日志、重启服务，不用再切到 Xshell 或者 PuTTY。

支持多标签页、独立窗口、查找、导出日志，我平时用着够用了。

CoreFTP SSH 终端

第三个是远程解压。

这个是我自己最常用的。

服务器上收到 zip 或者 tar.gz，以前我得先 SSH 进去，敲 unzip xxx.zip 或者 tar -xzf xxx.tar.gz。现在我右键一点，解压，完事。

还能选解压后要不要删原包。发版的时候真的省时间。

性能怎么样

我用 Tauri 2 写的，Rust 做后端。

任务管理器里看，空闲的时候内存大概 10 MB，CPU 0.1% 左右。

不是说它多厉害，就是我自己用着不心疼，常年开着也不卡。

CoreFTP 任务管理器内存占用

适合谁

个人站长、经常往服务器传文件的开发、小团队运维，这几个场景应该是最对口的。

当然我也不是说替代谁，FileZilla、WinSCP、Xshell 这些东西都很好，我也用过很多年。只是它们各管一摊，我想把常用的事情塞进一个窗口里，顺手就做出来了。

现在的情况

目前支持 Windows，macOS 和 Linux 也在做。

这是个个人项目，业余时间维护，更新不会像大厂那么快。但我自己每天都在用，遇到 bug 会修。
