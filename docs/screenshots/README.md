# 截图说明

将以下 PNG 文件放在本目录，README 会自动引用：

| 文件名 | 说明 | 建议尺寸 |
|--------|------|----------|
| `main-window.png` | 主界面（双栏文件管理、侧栏站点） | 1280×800 或同比例 |
| `ssh-terminal.png` | SSH 终端（多标签或独立窗口均可） | 1280×800 或同比例 |
| `site-manager.png` | 站点管理面板 | 1280×800 或同比例 |
| `main-window-dark.png` | 夜间模式 / 深色主题主界面 | 1280×800 或同比例 |

文件名需与上表一致；上传后无需改 README。
